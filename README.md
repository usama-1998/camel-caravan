# Camel Caravan — Landing Page

A premium landing page for **Camel Caravan**, a brand offering handcrafted furnishings rooted in Islamic heritage. Built with Next.js 14, React, and TypeScript.

## ✨ Highlights

- **Interactive Islamic Geometric Pattern Hero** — Full-screen canvas rendering tessellated 8-pointed stars, kite bridges, rosettes, and radial lines in desert gold on a rich dark background.
- **Autonomous Glow Animation** — A virtual cursor traces a smooth Lissajous path across the pattern, illuminating nearby geometry on page load.
- **Mouse-Reactive Interactivity** — Move your cursor across the hero to see the pattern glow and shift with multi-layer parallax.
- **Adaptive Navigation** — Light cream nav over the dark hero, transitioning to a frosted background on scroll.
- **Canvas-Based Rendering** — Geometric patterns at different scales with parallax depth, floating golden particles, and cinematic vignette. Featured in both Hero and CTA sections.
- **Responsive Design** — Fully responsive across desktop and mobile viewports, with touch support.

