# Camel Caravan — Landing Page

A premium landing page for **Camel Caravan**, a brand offering handcrafted furnishings rooted in Islamic heritage. Built with Next.js 14, React, and TypeScript.

## ✨ Highlights

- **Interactive Islamic Geometric Pattern Hero** — Full-screen canvas rendering tessellated 8-pointed stars, kite bridges, rosettes, and radial lines in desert gold on a rich dark background.
- **Autonomous Glow Animation** — A virtual cursor traces a smooth Lissajous path across the pattern, illuminating nearby geometry automatically on page load.
- **Mouse-Reactive Interactivity** — Move your cursor across the hero to see the pattern glow and shift with multi-layer parallax. Seamless blend between autonomous and real-mouse glow.
- **Adaptive Navigation** — Light cream-colored nav over the dark hero, smoothly transitioning to a frosted light background on scroll.
- **Canvas-Based Rendering** — Two layers of geometric patterns rendered at different scales with parallax depth, floating golden particles, and cinematic vignette. **Now featured in both Hero and CTA sections.**
- **Responsive Design** — Fully responsive across desktop and mobile viewports, with touch support for mobile interaction.
# Camel Caravan

Camel Caravan is a Next.js website dedicated to handcrafted furnishings that blend traditional Islamic heritage with modern design.

## Features

- **Hero Section**: Canvas-based interactive starry night animation with rotating text.
- **Philosophy**: Static content focusing on family and heritage.
- **Process (Craftsmanship)**: Overview of the bespoke design process.
- **Collection**: Grid of product categories with a premium "golden line" aesthetic.
- **Reviews**: Customer testimonials.
- **Journal (Instagram)**: Social media feed integration.
- **Contact**: CTA section with canvas animation.

## Recent Updates

- **Visual Revamp**: "Our Collection" section updated with golden borders, hover effects, and a light background.
- **Dynamic Text**: Rotating text effects added to Hero, Craftsmanship, Testimonials, Instagram, and CTA sections using the `TextRotator` component.
- **Navigation**: Updated Navbar to link to all sections.
- **Typography**: Standardized rotating text to use the "Cherish" font style (Cormorant Garamond Italic).
